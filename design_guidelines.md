# PokéVision Landing Page Design Guidelines

## Design Approach
**Reference-Based Approach**: Drawing inspiration from modern gaming and tech platforms like Discord, Notion, and premium SaaS products. The design emphasizes visual appeal and emotional engagement suitable for a gaming/tech audience.

## Core Design Elements

### A. Color Palette
**Dark Mode Primary**:
- Background: 15 8% 8% (deep charcoal)
- Surface: 20 6% 12% (elevated dark)
- Primary Gold: 45 95% 65% (vibrant gold)
- Gold Accent: 42 88% 55% (deeper gold)
- Text Primary: 0 0% 95% (near white)
- Text Secondary: 0 0% 70% (muted light)

**Gradients**: Subtle gold-to-amber gradients for hero backgrounds and accent elements. Use sparingly on hero section and key CTAs.

### B. Typography
**Font Stack**: Inter (primary), system fonts fallback
- Headings: 600-700 weight, generous line height
- Body: 400 weight, 1.6 line height
- Hero: Large, bold typography (48px+ desktop)
- Sections: Clear hierarchy with 32px, 24px, 18px scales

### C. Layout System
**Spacing Units**: Tailwind units of 4, 6, 8, 12, 16 for consistent rhythm
- Container max-width: 1200px with responsive padding
- Section spacing: py-16 to py-24
- Component spacing: Standard 4-6 unit gaps

### D. Component Library

**Navigation**: Sticky header with logo, nav links, and prominent CTA button

**Hero Section**: Full-viewport height with centered content, gradient overlay background, large heading with gold accents, dual CTAs (primary gold, secondary outline)

**Pricing Banner**: Clean horizontal banner with transparent pricing display, emphasis on "$20 per 10 sq km"

**CTA Cards**: Three equal-width cards (Discord, Demo, Sign Up) with hover states, subtle borders, and consistent spacing

**Feature Section**: Two-column layout highlighting key benefits with icon-text pairs

**Footer**: Simple single-row layout with copyright and secondary links

### E. Visual Treatments
- **Subtle shadows**: Use for card elevation and depth
- **Border radius**: Consistent 8px radius for modern feel
- **Hover states**: Gentle scale transforms and color shifts
- **Gold accents**: Strategic use on primary CTAs and key highlights

## Content Structure (5 Sections Maximum)
1. **Hero**: Value proposition with dual CTAs
2. **Pricing Banner**: Transparent pricing highlight
3. **CTA Cards**: Three primary action cards
4. **Features**: Two-column benefit highlights
5. **Footer**: Copyright and navigation

## Images
**No large hero image required**. The design relies on gradient backgrounds and typography for visual impact. Small decorative icons or logos may be used within feature sections and navigation.

## Key Design Principles
- **Gaming aesthetic**: Modern, sleek interface appealing to Pokémon GO players
- **Trust building**: Clean pricing transparency and professional layout
- **Action-focused**: Multiple clear CTAs guiding user journey
- **Performance-first**: Minimal animations, optimized loading
